# qlaude — implementation plan

Source spec: `docs/superpowers/specs/2026-11-16-qlaude-design.md` (the acceptance
rows A1–A7 are this plan's definition of done; each Review-Focus line below must be
exercised by a test or CI row).

Conventions: all shell files strict POSIX sh (`shellcheck -s sh` clean, severity
style). One function per gauntlet step so setup, doctor, and CI call identical code.
Stub server speaks only the shapes verified this session (see spec §5.8).

## T1 — repo skeleton + config layer
Files: `bin/qlaude` (skeleton: subcommand dispatch, usage, version, NO_COLOR
helpers, config read — read/case parse, never eval), `tests/stub_server.py`.
Tests: `shellcheck -s sh bin/qlaude`; `dash -n`; config parse unit via
`sh bin/qlaude config` on a fixture config.env; assert no `eval` in file (grep).
Review-Focus: config file treated as data; XDG resolution; exit-code constants.

## T2 — installer
Files: `install.sh`, `install.sha256` (generated by a tiny script committed under
`tools/gen-checksum.sh` — checksums over `bin/qlaude` + SYSTEM-PROMPT.md).
Tests: CI lint job; local: run installer with QLAUDE_INSTALL_DIR/CONFIG_DIR into
tmp, assert modes 755/600/0700s, PATH guidance printed when install dir not on
PATH, no rc-file mutation without ensure-path, `sh -x` trace clean under dash.
Review-Focus: no git, no install -D, no GNU-only tools; HTTPS-only; hasher ladder.

## T3 — launcher
File: `bin/qlaude` (default branch).
Tests: CI smoke — with stub, `qlaude --version` reaches claude (A5); token absent →
clear error, exit 1; exported-var assertion: launcher run under
`QLAUDE_DEBUG=env` prints the export list with token redacted (assert list matches
spec §5.3, token value never appears).
Review-Focus: `exec claude … "$@"` quoting; absolute claude path; keychain→file
ladder redaction; no eval.

## T4 — wizard (`setup`)
File: `bin/qlaude` (setup subcommand + flag parse `getopts`).
Tests: non-TTY without -y → exit 1 + usage (CI); full `-y` + env run writes
0600 config; trailing gauntlet runs; re-setup previews existing values; token via
`--token-stdin` never echoed (assert via `ps` + no tee-to-file).
Review-Focus: prompts to stderr; trailing whitespace on read; model probe failure
degrades to free text, never blocks; trailing-gauntlet exit code passthrough.

## T5 — gauntlet (steps 0–4) shared by setup/doctor
File: `bin/qlaude` (doctor + step functions).
Tests: CI smoke asserts steps 0–2 PASS vs stub (A2/A3); step-3 SKIP under
QLAUDE_STUB=1 (spec §5.8); step-1 auth-flip: start stub with require-bearer to
produce 401 once, assert hint text; wrong-path case (stub mounted at /api) produces
the /v1 hint.
Review-Focus: curl -m everywhere; --bare; exit-code map; NO_COLOR; fix lines
copy-pasteable; token never interpolated into printed strings.

## T6 — ensure-path + config subcommands
File: `bin/qlaude`.
Tests: marker-block idempotency (run twice → one block); refuse-to-clobber: seed a
`# qlaude PATH` block with foreign content → abort; --dry-run prints diff, touches
nothing; config redaction test (A4).
Review-Focus: Darwin→.zprofile, Linux→.profile; "open a new terminal" hint.

## T7 — CI workflow + stub polish
Files: `.github/workflows/ci.yml`, `tests/stub_server.py` (require-bearer toggle,
/v1/models list).
Tests: A1–A5 rows green on push (gh run watch); mac job under ~5 min wall clock.
Review-Focus: macos-15 pinned; npm channel + `claude --version` smoke per official
setup docs; secrets unused (stub token is dummy `stub`).

## T8 — README quickstart + docs polish, release
Files: `README.md` (Quickstart ≤5 lines; link to spec), `docs/` links.
Tests: A6 review by cold reader (lane); A7 = owner manual matrix (external, tracked
in repo TODO/issues after merge).
Review-Focus: quickstart matches README's verified table exactly; no internal
hostnames anywhere in repo (public repo rule — grep for the leak pattern before
push, re-run the history scan too).
